## 简介

Tsuyomi 是一款本地优先、面向墨水屏的跨平台轻小说阅读器，这里是它的 **iOS 客户端**。

出于运行效率的考虑，iOS 端计划用 Swift 做原生开发，会等 Android 端的基础功能大体完成之后再动工。所以在功能齐全之前，这边的进度会比 Android 端慢上一些
