# 设置项与功能项适用性（iOS）

判定顺序与可见性矩阵沿用 `tsuyomi-android/docs/design/OPTION_APPLICABILITY.md`：**已实现 → 具备能力 →
当前生效 → 需要解释 → 反馈完整**。下表逐项回答"为什么可见、何时生效、无效时为何隐藏或禁用"。

E-ink / DisplayProfile 整族在 iOS 上不存在（无墨水屏设备类别），因此 Android 版围绕 profile 的
"保留值并禁用"规则在此没有对应项：这些控件不是被隐藏，而是根本没有被移植。

## 显示与阅读

| 项 | 呈现 | 为什么 |
|---|---|---|
| 外观（跟随系统 / 浅色 / 深色） | 可见可操作 | 立即改变整个界面；`AppPreferences.colorScheme` 是唯一来源 |
| DisplayProfile 选择 | 不存在 | iOS 无墨水屏设备类别，第 4 节已删除整族 |
| E-ink 立即重绘 | 不存在 | 同上 |
| 阅读器字号 / 行高 / 边距 / 段距 | 可见可操作 | 改变排版度量键，立即重新分页；语义位置不变 |
| 阅读方式（滚动 / 分页 / 双页） | 可见可操作 | 三种呈现共享同一个 locator；切换不重新解析位置 |
| 配色 | 可见可操作 | 只改颜色，不进入 layout key，因此不会作废分页 |
| 锁定竖屏 / 沉浸 / 不息屏 / 显示进度 | 可见可操作 | 均有真实 handler 且立即生效 |
| 音量键翻页 | 不存在 | iOS 不提供可用于翻页的音量键事件，第 4 节已删除 |

## 来源与扩展

| 项 | 呈现 | 为什么 |
|---|---|---|
| 进入来源首页 | 仅当扩展声明 `home` 能力时可见 | 未声明时该来源没有首页，显示入口会暗示不存在的能力 |
| 网站收藏（只读拉取） | 仅当声明 `remoteLibrary.read` 时可见 | 同上 |
| 同步到网站收藏 | 仅当声明 `remoteLibrary.add`、已授权写回、来源可用且凭据就绪时可见 | 六条远端写入条件任一不满足即无法完成，显示按钮即是假入口 |
| `加入书架` | 始终可见 | 无条件本地写入，不依赖任何来源能力 |
| 登录 / 站点验证 | 仅当声明 `webLogin` 且有声明 origin 时可见 | 无声明 origin 时受控浏览器会拒绝打开 |
| 扩展市场入口 | 始终可见 | 没有任何仓库时首页直接展示"添加仓库"与说明 |
| 内置官方仓库 | 不存在 | 基址与根公钥未定；不写占位 URL |
| 安装 / 更新按钮 | 已撤销包禁用；hostApi 不兼容显示为不兼容态 | 撤销与兼容性是用户无法解除的前置条件，需说明原因而非隐藏 |
| 移除发布者信任 | 可见，带二次确认 | 会立即停用其签名的全部扩展，后果必须在确认文案里说清 |

## 书架

| 项 | 呈现 | 为什么 |
|---|---|---|
| 拖拽排序（插入位让位） | 仅在"排序整理"模式下 | 同一拖放手势不能既表示排序又表示建收藏夹 |
| 排序方式 / 倒序 | 可见可操作 | 纯投影，立即可见 |
| 快捷栏重排 | 仅在未锁定时可进入编辑列表 | 锁定即用户明确表达"不要再动"，此时按钮变为解锁 |
| 系统节点隐藏 / 恢复 | 长按菜单中可见 | 隐藏的是入口不是数据，恢复项始终列在同一菜单里 |
| 智能收藏夹规则编辑 | 可见可操作 | 违规按 `path` 内联回对应行；未保存返回二次确认 |

## 数据

| 项 | 呈现 | 为什么 |
|---|---|---|
| 导出 | 可见可操作 | 立即产生文件；页面明写包含与不包含项 |
| 导入 | 可见可操作 | 预览计划前不写库；执行后给出报告 |
| 导入报告 | 仅在存在已完成会话时可见 | 无会话时没有可展示的结果 |
| 账号 / 云同步 / 使用统计 / 崩溃上报 | 不存在 | 第 2 节不变量：本地优先，无账号无遥测 |

## 无障碍与反馈

- 所有可操作控件最小触控目标 44pt；折叠后的快捷栏是一条整宽 ≥44pt 手柄，不会把唯一入口缩到目标以下。
- 非内容态（载入 / 空 / 离线 / 失败）统一由 `StateView` 绘制，失败态始终提供重试。
- 失败只展示稳定错误码与固定文案，不展示原始 HTML、Cookie、URL 或 JS 栈。
- 反馈不依赖动画：插入位让位动画之外的所有状态都以持久文本呈现。
